A unique 6-character test code is generated automatically. Share it with students so they can log in and take the exam.

File Format Guide

Each question must follow this exact structure. Any question without an Answer: line will cause the upload to fail. 

1. What is the capital of France?
A) London
B) Berlin
C) Paris
D) Madrid
Answer: C

2. Which planet is the Red Planet?
A) Venus
B) Mars
C) Jupiter
D) Saturn
Answer: B
  • Questions start with a number followed by . or )
  • Options use A) through D) — exactly 4 per question
  • Answer: X must appear after every question (X = A, B, C, or D)
  • PDFs must contain selectable text — scanned images won't work

CSV is the most reliable format. Use a spreadsheet app and export as CSV. 

question,option_a,option_b,option_c,option_d,answer
What is the capital of France?,London,Berlin,Paris,Madrid,Paris
Which planet is the Red Planet?,Venus,Mars,Jupiter,Saturn,Mars
  • Header row is required with exactly these column names
  • The answer column must contain the exact text of the correct option
  • All 6 columns are required — leaving any empty rejects the upload
  • Save as UTF-8 CSV (not Excel .xlsx)
